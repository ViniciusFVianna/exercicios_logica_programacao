# 🚀 Logic & Paradigms Study Lab
Repositório dedicado ao estudo aprofundado de lógica de programação, explorando múltiplas linguagens e a aplicação de paradigmas modernos de desenvolvimento.

## 📌 Sobre o Projeto
Este projeto foi criado como um laboratório prático para consolidar conceitos fundamentais e avançados de engenharia de software. A principal motivação é resolver desafios lógicos e algoritmos estruturais — desde operações matemáticas e lógicas (como calculadoras e conversores de bases numéricas) até lógicas de controle e integração com hardware. O foco não é apenas fazer o código funcionar, mas estruturá-lo aplicando boas práticas, padrões de projeto e testes de arquiteturas escaláveis.

## ✨ Funcionalidades
- [x] Implementação de algoritmos clássicos de lógica e conversão de dados.
- [x] Exploração de paradigmas (Orientação a Objetos, Funcional e Reativo).
- [ ] Criação de interfaces iterativas para visualização de cálculos e lógicas de negócio.
- [ ] Construção de documentação detalhada para lógicas de integração com sistemas físicos/embarcados.

## 🛠️ Tecnologias e Ferramentas
- **Linguagens:** Dart, C++
- **Frameworks:** Flutter
- **Arquitetura:** Clean Architecture
- **Outros:** Prototipação (Figma), Arduino IDE para testes de lógica de baixo nível.

## 🏗️ Estrutura do Projeto
A organização do código segue princípios de separação de responsabilidades para manter os estudos sempre organizados e independentes:

```text
lib/
├── core/          # Código compartilhado, utilitários e configurações globais
├── data/          # Repositórios e Data Sources (manipulação de dados e APIs)
├── domain/        # Entidades e Casos de Uso (regras de negócio puras e lógica central)
└── presentation/  # UI, protótipos de tela e Gerenciamento de Estado
```
