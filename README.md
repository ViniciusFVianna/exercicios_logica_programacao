# 🚀 Logic & Paradigms Study Lab
Repositório dedicado ao estudo prático de lógica de programação por meio da implementação de soluções em múltiplas linguagens, com foco na comparação de sintaxe, estruturas e paradigmas.

## 📌 Sobre o Projeto
Este projeto foi criado como um laboratório de exercícios para consolidar conceitos fundamentais da programação e da resolução de problemas lógicos. A proposta principal é explorar a mesma lógica em diferentes tecnologias, permitindo comparar como cada linguagem aborda estruturas condicionais, entrada e saída, organização de código e paradigma de desenvolvimento.

O repositório reúne implementações em C/C++, Dart, Java, Kotlin, Node.js e Python, organizadas em pastas separadas para facilitar estudo, execução e comparação entre as soluções.

## ✨ Funcionalidades
- [x] Implementação do mesmo exercício em várias linguagens.
- [x] Comparação entre sintaxes e estruturas de controle.
- [x] Organização por linguagem para estudos independentes.
- [ ] Expansão para mais exercícios e desafios de lógica mais complexos.
- [ ] Documentação detalhada de cada solução e suas particularidades.

## 🛠️ Tecnologias e Ferramentas
- **Linguagens:** C/C++, Dart, Java, Kotlin, JavaScript, Python
- **Ambientes de execução:** compilação local, Node.js, JVM e interpretadores Python
- **Objetivo:** estudo de lógica e comparação entre paradigmas e técnicas de implementação
